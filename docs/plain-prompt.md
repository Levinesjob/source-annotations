# 不安装 skill 的文字试用

将下面指令和有权处理的论文交给能够读取全文的AI工具。它只能帮助生成文字解释，不保证导出原版式标注PDF。

> 请先通读这份论文正文，说明实际读到的版本、范围，以及无法读取的部分。
> 按原文出现顺序选出：必须理解的主张、机制、结果与限制；本文语境下容易误解的词；真正影响理解的长句。
> 每条保留准确原句和页码。难词只给本文义；长句先直译，保留条件、否定、指代与比较对象，必要时补一句解释。
> 难句不一定是重点。不要把所有术语都标出来，不用摘要倒推重点，不重复改写同一结论。区分作者主张、实验结果和你的推断。
> 不能确认的原句位置、数值或解释，明确列出缺口，不假装读过或核实。最后指出最需要人复核的地方。

全文读取能力、上传限制和费用取决于你所用工具。先用少量页面检查解释质量，不因为工具给出完整答案就认为它已读完全文。
