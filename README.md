## 开始使用

复现已有样例无需模型或 API Key，需要 Python 3.11+ 和 requirements.txt 中的依赖。生成 PDF 与手机 HTML 的命令，以及 Skill 安装方式，见[完整用法](docs/usage.md)。全文产物仅本地生成。
