# academic-native：学术原生导览

用于在论文之前插入一页中文阅读导览；不重新实现翻译、高亮或旁注。

先用 `academic_guide.analyze_pdf` 记录原页纸张、方向、文字外边距、主体字体类别和字号、标题字号、栏数、页眉页脚及细分割线。识别是基于原生文字的启发式结果，必须查看渲染图；缺少文字层时不能声称已准确识别版心。

导览采用原论文首页的尺寸及方向、可用的外侧版心。即使原文双栏，导览仍用单栏。黑色正文、灰色辅助信息、细灰线分组；只用一种低饱和蓝色表示链接。禁止卡片、底色块、渐变、阴影和装饰图标。

- 中文标题16–19pt；模块标题11.5pt。
- 正文优先10.5pt，必要时在10/9.5pt内适配；行距1.28。
- 资料入口与身份辅助信息8.5pt，不能用此字号承载主体解释。
- 中文嵌入Noto Serif CJK SC；英文嵌入Nimbus Roman，与常见Times系预印本协调。不复制来源不明的系统字体。
- 内容放不下一页则停止，先压缩重复解释、作者介绍之外的次要文本和先修知识；不再向下缩小字号。

顺序：论文身份 → 核心观点 → 先修知识 → 最多五项阅读路径 → 证据图例。边界优先融入最后一项。标题是导读者的中文概括，其下单列原论文英文标题，不能让两者混淆。

每项直接解释是什么，不用“先抓问题”等任务提示替代信息。入口写清论文PDF页序及章节/图表/公式名称；能精确定位时使用实际坐标，不能时显示“整页入口”。印刷页码与PDF物理页序分开，不把前置页的偏移重复计算。

字体必须可检索，最终PDF不得以整页截图充当导览文字层。查看导览截图，并检测文字越界、替换字符、链接目标和书签。

## 两条导出路径

1. **只加导览**：`prepend_guide.py`直接在原PDF对象树插页，保留原页。逐页对比像素和文字，核对已有链接、批注、表单值、附件字节、元数据、页标签与书签。原始命名书签会解析为等价GoTo目的地，不保留其原始书签动作编码。输入不覆盖；先保存临时文件、通过验证后再交付。
2. **既有标注导出**：`annotate.py`继续使用原有注释流程，只复用新导览模块。此旧流程会重建研究页，不能宣称拥有“只加导览”路径的全部结构保留能力；已有批注/表单仍拒绝处理。p3–4不扩边试排是本案例单独授权的布局调整，不改变其他页的默认行为。

加密、修复后结构异常、旋转/非平凡裁剪、签名文档会停止并说明。原标签树会保留，但新增页未做PDF/UA语义标记；没有验证完整标签语义。XFA、作品集及富媒体不在已认证范围。不能把这些结构的存在检测说成完整支持。
